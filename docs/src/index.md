# Vellum.jl

Vellum draws paths, text and images into an immutable frame. Start with the
[route tutorial](route.md) to produce a headless CPU image, then export the
same drawing for interactive replay in a browser.

- [Hover live Binance candlesticks](candlesticks.md) and change the host between the browser, Wayland and X11.
- [Orbit a labeled 3D surface](surface_plot.md) built from a depth-tested triangle mesh.
- [Build a reading-light interface](touch_controls.md) with a switch, brightness slider and color selector.

The API reference in the sidebar groups public and private definitions by
Julia source file. Use search to find a function, type or constant by name.

[Build a retained signal dashboard](signal_desk.md) to connect gradient meters and trends to one selection.
[Animate a translucent market panel](glass_market.md) to add playback and scrubbing to the same components.
[Build an animated glass toolbar](glass_controls.md) to give reusable map switches pointer, touch and keyboard feedback.

[Build a Liquid Glass UI framework](liquid_glass.md) to implement a sound panel with reusable controls, input feedback, refracted wallpaper and a cast shadow.
